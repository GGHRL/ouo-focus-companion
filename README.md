# OuO 陪你专注

一个黑白风格的互动陪伴和专注计时原型，支持表情互动、番茄钟、喝水记录与提醒、备忘录、星星和离线使用。

## 网页版

根目录包含可直接部署的静态网页。使用支持 HTTPS 的静态托管服务，或在本地使用 HTTP 服务器打开。iPad 用户可在 Safari 中添加至主屏幕，首次联网完成离线准备后可尝试离线打开。备忘录和学习记录存储在当前浏览器或网页应用的本地存储中。

## OPPO 手表版

`watch-source.zip` 包含适配 OPPO Watch 3 Pro 的 Android 项目源码，以及使用说明。该版本使用本地 WebView 和手表动作传感器。安装包须使用 Android SDK 构建并签名。

## 项目状态

个人学习和交互实验原型。OuO 相关名称、形象和设计的权利状态需要发布者自行核实。此仓库暂不附加开源许可证。
